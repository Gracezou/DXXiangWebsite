**这是当前的生产版本。** 在 `v2.0.0` 基础上完成 7 个批次：迁移到 Nuxt 4、彻底移除 Element Plus、按境外科技公司门户的设计语言重做视觉、并加入 AI 赋能内容。

## 视觉重构

v2.0 的视觉被评价为不好看，重新提案后按新方向重做。

**方向**：深色技术流 + 克制专业流的内容排布。

- **强调色改用琥珀金 `#E0A458`** —— 深蓝的互补色，在科技站中罕见（同类几乎清一色蓝绿紫），能中和深蓝的冷硬。品牌蓝 `#003153` 保留但降级为**结构色与氛围光晕**
- **弃用图库照片直出** —— 服务卡片改用内联 SVG 几何图形，不再受原图比例限制（原先 4:1 的图被 16:9 强裁后构图尽毁）；保留使用的照片降为纹理
- **首页去掉三屏轮播**，改为单一 Hero + 明确主张 + 主次 CTA。原轮播内容下沉为并列的服务卡片
- **边框系统取代投影**，字号拉到 88px 并收紧字距，与说明文字拉开数量级
- **字体自托管**：Sora + IBM Plex Sans/Mono 拉丁子集（148 KB），中文走系统字体。不使用 Google Fonts CDN

## 修复的问题

| 问题 | 说明 |
| --- | --- |
| **hydration mismatch** | Nuxt 4 + i18n v10 下 cookie 驱动的语言切换与预渲染 HTML 不一致，访问 `/` 会渲染成英文。已关闭浏览器语言检测，语言完全由 URL 决定 |
| **图片未声明宽高** | 未加载时高度为 0，浏览器判定不可见而不触发 lazy 加载。14 张图全部补上 `width`/`height`，CLS 归零 |
| **中英混排字距** | `-0.035em` 是为拉丁字母设计的，中文等宽方块字同样收紧会挤在一起；`13ch` 行宽还会把中文标题断在词中间。已按 `html[lang]` 分设 |
| **氛围层等于白做** | 网格实际可见度是 `0.09 × 0.5 = 0.045`，深底上亮度差仅 10/255。已给足对比并补品牌蓝光晕 |
| **中西文缺空格** | 修正 3 处（`构建先进的 IT 系统` 等） |
| **横向溢出** | 全站补 `box-sizing: border-box`，修复 `width:100%` + padding 撑出滚动条 |

## 未采纳与未执行

**入场动效与滚动显现**：实现后主动移除。两个原因——

1. 滚动显现依赖 IntersectionObserver，实测在验证环境中**完全不触发**（探针元素观察 1.5 秒零回调），无法验证的特性不上线
2. 任何「从 opacity 0 淡入」的动画都有固有风险：动画一旦未执行，元素**永久停在透明状态，内容彻底不可见**。收益是一次性淡入，代价是可能整屏空白

只保留 hover/focus 的 `transition` —— 它只在状态变化时生效，不影响元素初始可见性。已建立验收方法：注入 `*{animation:none;transition:none}` 模拟最恶劣情况，确认内容仍完整可见。

**案例板块与合作伙伴 logo**（C4）：因缺少首批内容与素材未执行。空的列表页对 SEO 是负面的，内容到位后可随时补做。
