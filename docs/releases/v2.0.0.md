# v2.0.0 — 网站现代化升级

> 本版本作为版本记录发布。生产部署请使用 **v2.1.0**。

在 `v1.0.0`（2023 年 4 月）基础上完成 5 个批次共 31 项改造，修复法律与可信度层面的硬伤，把停留在 2023 年初的技术栈拉回可维护状态，并补齐移动端、SEO 与国际化。

---

## 修复的缺陷

| 问题 | 说明 |
| --- | --- |
| **隐私政策残留他司名** | 正文出现「符合**谦益**本隐私政策」，是从其他公司文本复制时的遗留 |
| **路由拼写错误** | `/abort`（中止）实为 `/about`，出现在 URL 与两处导航中 |
| **Logo 点击跳到 `/0`** | `el-menu` 的 `router` 模式把 `index="0"` 当作路由路径 |
| **解决方案页断图** | 一处 `<Image>` 没有 `src`，线上长期显示破图占位符 |
| **首页空板块** | 「客户及合作伙伴」只有标题没有内容 |
| **拼写与命名** | `logan` → `slogan`，`technolog_solution_provider.jpg` → `technology_…` |
| **无 404 页** | 输错地址会看到 Nuxt 默认报错页，暴露技术栈 |

另外补上了页脚版权行与 **ICP 备案号配置位**（留空时不渲染，填入即生效）。

## 技术栈升级

```
Nuxt          3.2.3  →  3.21.11
element-plus  2.2.30 →  2.14.5
UnoCSS        0.49   →  66.x
TypeScript    4.9    →  5.9.3
pnpm          7.20   →  10.34.5
```

同时切换为**静态生成**（`nuxi generate`），移除了 `build` 脚本里那段不跨平台的 popperjs 补丁（实测升级后已不需要），并删掉了会覆盖全局监听器的 `window.onresize`。

## 中英双语

全站文案抽离到 `i18n/locales/`，**114 个键 × 2 种语言**。中文为默认语言不带前缀，英文走 `/en/*`。含语言切换、`hreflang` 互指与 canonical。

改文案不再需要动 `.vue` 文件。

## 设计基础与性能

- 建立**设计令牌层**：修复了 v1.0 只写 `"Microsoft YaHei"` 单个字体名的问题（macOS/iOS 会掉到宋体）；19 个散落的间距值收敛为阶梯；色值语义化
- **移动端响应式**：v1.0 是固定像素布局，手机上会横向溢出。新增汉堡菜单、`clamp()` 字号、弹性栅格
- **SEO**：各页独立 title/description/OG/Twitter、`titleTemplate`、Organization 与 BreadcrumbList 结构化数据、sitemap 与 robots
- **图片**：接入 `@nuxt/image`，自动 WebP 与响应式 `srcset`，全站补 `alt`
- **对比度**：正文色由 `#848e97` 调深至 `#5a6572`，满足 WCAG AA

## 工程化

ESLint + Prettier、GitHub Actions（PR 跑 lint/format/generate）、README 从 Nuxt 官方模板原文重写为项目实际文档。
